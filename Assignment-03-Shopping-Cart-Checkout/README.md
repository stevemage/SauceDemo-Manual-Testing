# Assignment 3 — Shopping Cart & Checkout Testing

Manual QA portfolio exercise for [SauceDemo](https://www.saucedemo.com/).

## Scope
Shopping cart addition/removal, multi-item behavior, prices, required checkout fields, order overview, purchase completion and cancellation. Covers **REQ-008–REQ-015** and **TC-008–TC-018**.

## Outcome
- 11 test cases; latest recorded outcome: **11 PASS / 0 FAIL / 0 BLOCKED**.
- TC-017 had an earlier FAIL against an exercise assumption about cancellation navigation; after clarification of the assumed requirement, it was revised and re-executed PASS. The earlier result is retained as history.
- No confirmed application defect was identified within this exercise.
